# Mesto

Интерактивная страница, на которой можно редактировать профиль, обновлять аватар, добавлять и удалять карточки, ставить лайки. Все данные загружаются с сервера и сохраняются через REST API.

## Функциональность

- загрузка профиля пользователя и карточек с сервера;
- редактирование профиля и обновление аватара;
- добавление новых карточек;
- удаление своих карточек (кнопка удаления есть только у карточек текущего пользователя);
- постановка и снятие лайков со счётчиком;
- статистика карточек по клику на логотип (дополнительное задание);
- валидация форм и отображение состояния загрузки при отправке.

## Технологии
